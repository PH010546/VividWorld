# 鮮活世界：各有其道

*Vivid World*

《Mount & Blade II: Bannerlord》的單人模組。**讓卡拉迪亞的人們活起來。**
各種事件會在他們之中發生，話會傳開，並在半路走樣。他們會記住，也會忘記。
而你可以成為其中的一份子。

*[English](README.en.md)*

> **本版為 beta（v0.9.1）。**
> 核心機制均已完成並經實機運行，內容仍在擴充。後續規劃請見文末的〈開發藍圖〉。

## 功能概述

**消息會自行產生。** 模組掛鉤遊戲本身的五類事件——死亡、俘虜、結婚、生子、釋放——
並依情況細分為九種消息：其中「死亡」依死因分為謀殺、處決、戰死與自然死亡四種，
「釋放」則分為獲釋與逃脫兩種。
此外另有六種自創事件會自然發生：宴席上的座位之爭、向老兵討教兵事、酒後失言、
爭搶戰功、市集衝突，以及狩獵時的賭注。

**消息以口耳相傳，並在過程中走樣。** 每隔一段時間NPC領主會各自從記憶中挑一件事講給身邊的人聽。
同一件事每多轉述一手，就遺失一部分細節——
時間、地點、在場者會逐項消失。傳到第五手時，聽到的往往只剩「某人在某處做了某事」。

**大事傳得遠，小事傳不動。** 每一種消息各有份量：新生兒的消息傳兩手即止，
君主遇刺則可傳六手，足以走遍半個大陸。

**人會遺忘。** 與當事人素無交情者僅能記住數日；被反覆提起的事記得較久；
當所有知情者都遺忘之後，那件事便就此沉寂。

**聽到消息會改變關係。** 消息傳入誰的耳中，誰就依該事件應有的份量改變對當事人的好感度——
親眼目睹者計全額，僅得自傳聞者遞減，每多轉述一手再折減一次。**你自己的作為同樣會被議論。**

**衝突會留下樑子。** 領主之間的摩擦會記進模組自己的「恩怨帳本」——誰為了哪件事、對誰、積了多少。
這本帳管的是**私怨什麼時候會升級成兩個家族之間的世仇**：積怨夠深，而且當事人是族長本人或族長的血親，
樑子就從兩個人之間擴大成兩個家族之間。積怨會隨時間消退，但消退到一定程度就停住，不會完全一筆勾銷。

## 安裝

**適用的遊戲版本：** 針對 **v1.4.8** 建置，其他版本尚未測試。

1. 解壓縮後，將 `VividWorld` 整個資料夾置於遊戲的 `Modules\` 目錄下
   （例如 `...\Mount & Blade II Bannerlord\Modules\VividWorld\`）。
2. **另需安裝 Mod Configuration Menu（MCM）**，並讓它排在本模組之前載入。
3. 於啟動器的模組清單中勾選 **Vivid World**，順序置於 Native、SandBoxCore、Sandbox、StoryMode 之後。
4. 無須另行安裝 Harmony。

**移除：** 刪除模組資料夾即可。建議刪除前先備份。

## 遊戲中的接觸方式

**主動詢問。** 與任何領主對話時，選單會多出一句「最近路上有什麼消息嗎？」。
他知道什麼便說什麼，無可奉告時則回以「沒什麼值得一提的事」。
**向陌生人問不出消息屬於正常現象**——是否願意開口，取決於他對你的好感度與他的個性
（慷慨與榮譽使他樂於分享，算計則使他緘默），未達門檻即無所獲。這是設計的一部分。

**對方主動告知。** 領主有時會在開口之際便將聽來的消息告訴你，無須詢問。
若你安裝的其他模組接管了對話的開場白，選單會多出一句「你剛才似乎欲言又止？」作為補救管道。

**回顧紀錄。** 按 **Ctrl+L** 開啟「你聽過的事」，其中列出你至今聽聞的每一則消息，
並標示轉述手數與告知者。傳聞文字中的人名與地名可點選，連往遊戲的百科。

## 存檔安全

模組的資料**不寫入遊戲的存檔檔案**，而是另存於
`Documents\Mount and Blade II Bannerlord\Configs\VividWorld\` 之下。

由此衍生兩件事：

- **移除模組後，既有存檔仍可正常讀取。** 存檔內不含任何屬於本模組的資料。
- **將存檔移至另一台電腦時，傳聞資料不會隨之移轉。** 若需一併移轉，請複製上述資料夾。

## 設定

設定檔位於：

```
Documents\Mount and Blade II Bannerlord\Configs\VividWorld\config.json
```

首次啟動遊戲時會自動產生。同一資料夾內的 `_README.txt` 說明了各檔案的用途。

較常調整的項目如下：

| 設定鍵 | 預設值 | 作用 |
|---|---|---|
| `enabled` | `true` | 模組總開關 |
| `presentation.chronicleHotkey` | `"Ctrl+L"` | 開啟「你聽過的事」的按鍵 |
| `presentation.snapshotManagerHotkey` | `"F9"` | 開啟快照清單的按鍵 |
| `persistence.maxSnapshots` | `0` | 快照保留份數上限，`0` 表示不限制 |
| `debug.logTellerTurns` | `false` | 將每一次轉述寫入 `log.txt`。回報問題時可開啟 |

熱鍵可加上修飾鍵前綴，例如 `"Ctrl+L"`、`"Alt+K"`、`"Shift+F9"`，亦可僅填單一鍵名如 `"L"`。

**模組更新後不會改動你既有的設定值。** 僅補上新版新增的設定鍵；
你自行調整過的值，乃至模組已不再辨識的設定鍵，一律原樣保留。

**遊戲的設定畫面裡也有一頁 Vivid World**（由 Mod Configuration Menu 提供），
分成八組、共 24 個項目，可以直接在遊戲裡改，改完立刻寫回上面那個 `config.json`；
選單上沒有的設定維持原樣。

## 相容性

**「平民不應與貴族攀談」一類的模組**（例如 NaN、Lowborn）：本模組可偵測其存在並自動進入相容模式，
將「主動詢問傳聞」限制於家族等級 1 以上。**家族仍為等級 0 時將問不到任何消息**，
此為刻意配合該類模組的設計。

**接管對話開場白的模組**：部分模組會完整接管領主的第一句話，使本模組無從開口。
遇此情形時，對話選單會多出一句「你剛才似乎欲言又止？」，供你將話題引回。

本模組不修改遊戲本身的 AI 決策，亦不覆寫任何原生檔案。

## 回報問題

日誌位於：

```
Documents\Mount and Blade II Bannerlord\Configs\VividWorld\log.txt
```

回報時請一併附上。若問題與「誰向誰轉述了什麼」有關，
請先將 `config.json` 中的 `debug.logTellerTurns` 設為 `true`，重啟遊戲後重現該情形，日誌將詳盡得多。

## 開發藍圖

卡拉迪亞的人際往來還有很長的路。以下是我們正在推進的方向：

| 項目 | 目標 |
|---|---|
| **更多自創橋段** | 讓領主之間自行上演的場面持續增加，從宴席、軍旅到市井與家族之間的往來，各有各的戲 |
| **傳聞會被加油添醋** | 消息不只會在轉述中遺失細節，還會被誇大、被渲染，愈傳愈不是原本那回事 |
| **當面把話說清楚** | 當你聽來的版本與事實有出入，能在對話中向當事人求證，把誤會攤開 |
| **衝突會有來有往** | 一場爭執不再是一次定勝負；加入決鬥一類的對抗，讓雙方各有回應 |
| **結局牽動得更廣** | 讓橋段的結果不只改變關係，也能觸及金錢、名望、影響力，乃至人身安危 |
| **你也能開口** | 主動散播消息、從中挑撥，讓傳聞成為你手上的一件工具 |
| **更多消息來源** | 改換王國、叛變、攻城陷落這類大事，也會在他們之間傳開 |
| **與 AI 對話模組銜接** | 讓「誰知道什麼、誰對誰有心結」這些資料能提供給以 AI 驅動對話的模組，使他們談起這些事時不只有固定的說法 |
